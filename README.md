# 💻 Sobre mí

Soy desarrollador **Full Stack** especializado en crear soluciones empresariales para logística, ingeniería, transporte y administración de flotas.

Actualmente lidero el desarrollo de **CMOCS**, una plataforma web para administración de vehículos, mantenimientos, GPS, conciliaciones, documentación, órdenes de trabajo e integración con SIIGO.

Mi objetivo es desarrollar software moderno, escalable y de alto rendimiento.
